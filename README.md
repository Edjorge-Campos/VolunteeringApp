# VolunteeringApp

A native Android application developed to optimize and streamline volunteer management, work schedule organization, and real-time attendance tracking for shifts and events.

---

## Motivation

As an active volunteer every Sunday, I regularly encountered a challenge: coordinating which volunteers would participate in specific shifts. 

To solve this real-world issue within my community, I developed **VolunteeringApp** to organize shift scheduling, automate sign-ups, and deploy a practical solution intended for real-world usage within my organization. I intend on continuing the app to eventually get it to be used by my volunteering group.

## Key Features

- **Shift & Schedule Management:** Clear display of shift timings, available openings, and task details.
- **Real-Time Attendance:** Enables volunteers to independently sign up for or cancel shift attendance.
- **Authentication & User Profiles:** Secure access with role-based permissions for volunteers and managers.
- **Cloud Synchronization:** Real-time database updates to ensure capacity and attendance data are always current.

---

## Tech Stack

- **Language:** Java
- **Platform:** Native Android (Android Studio)
- **Backend & Cloud Services:** Firebase (Cloud Firestore & Authentication)
