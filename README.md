# 📱 VolunteeringApp

Desenvolvi uma aplicação Android, para otimizar a gestão de voluntários a gestão de voluntários, organização de escalas de trabalho e confirmação de presença em turnos/eventos em tempo real. Eu faço voluntariado, todos os domingos, e um problema muito comum e que encontro todas as semanas, é o facto de ser difícil organizar que voluntários vão participar de que turnos, logo decidi criar esta aplicação para resolver este problema tornando mais fácil toda este gestão, o meu objetivo é conseguir introduzir a minha app ao meu grupo de voluntários para ser utilizada por users reais.

## ✨ Principais Funcionalidades

- **Gestão de Turnos e Escalas:** Visualização clara dos horários, vagas disponíveis e detalhes das atividades de voluntariado.
- **Inscrição em Tempo Real:** Permitir que os voluntários se inscrevam ou cancelem a presença de forma autónoma.
- **Autenticação & Perfis de Utilizador:** Acesso seguro com gestão de permissões para voluntários e organizadores.
- **Sincronização em Nuvem:** Base de dados em tempo real para garantir que as vagas e presenças estão sempre atualizadas.

---

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Java
- **Plataforma:** Android Nativo (Android Studio)
- **Backend & Cloud:** Firebase (Firestore / Authentication)
- **Interface UI:** XML / Material Design Components

## 🚀 Como Executar o Projeto Localmente

### Pré-requisitos
- Android Studio Flamingo / Hedgehog ou superior
- JDK 17 ou superior
- Dispositivo físico Android com depuração USB ativada **ou** um Emulador Android (AVD)
